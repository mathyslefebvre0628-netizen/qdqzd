# Auto Save

Mod Fabric Minecraft 26.2 basé sur SaveMod, avec :

- le système de sauvegarde/chargement ;
- la liste, recherche, renommage, duplication et suppression ;
- le raccourci d'ouverture ;
- un raccourci de sauvegarde ;
- sauvegarde automatique activable/désactivable ;
- intervalles 1, 5, 10, 20, 30, 40 minutes et 1 heure ;
- configuration Mod Menu en français ;
- logo personnalisé.
